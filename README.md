# TM Workbench Admin（提名教育工作台）

面向咨询业务团队的**客户管理工作台（CRM）**，基于 `vk-unicloud-admin` 框架二次开发。用于统一管理客户信息、咨询进度、线索来源、签单信息和客户资料，支持多角色协作与严格的业务数据隔离。

---

## 一、功能特性

### 客户管理

- **客户信息管理**：维护家长姓名、孩子姓名、联系电话、微信号、线索来源、咨询状态、线索成本、是否重点客户等基础信息。
- **客户列表与详情**：支持多条件组合查询、分页浏览、按状态/来源/质量筛选；点击行或详情按钮进入客户详情，集中查看客户资料、跟进进度、签单信息和文件。
- **新增 / 编辑 / 转移**：管理员或线索老师可新增客户并分配咨询师；客户可在咨询师之间转移（写入转移记录并通知双方）。
- **批量导入 / 导出**：支持 Excel 模板下载、批量导入客户、导出当前查询结果。
- **回收站与彻底删除**：软删除进回收站可恢复；管理员/运营管理员可彻底删除（不可恢复）。
- **重点客户**：标记/取消重点客户，重点客户在首页集中展示。

### 状态与进度

- **客户状态字典化**：7 种状态（初步沟通 → 沟通中(能转化)/沟通中(难转化) → 已邀约 → 已签单，可回退已退单，任意状态可转不考虑），编码固定不变，修改配置不影响历史数据。
- **状态管理页**：管理员可维护状态名称、排序、客户质量分类、启停用（停用不影响历史数据）。
- **跟进记录**：以时间线记录每次沟通，支持新增/编辑/删除；记录的状态自动同步为客户当前状态；系统自动记录转移、删除、恢复等系统事件。
- **签单信息**：已签单状态下维护签单省份、城市、合同金额、合同主要内容。

### 线索来源

- **来源字典化**：视频号线索、抖音线索、老客户、客户转介绍、其他来源，支持自定义来源与启停用。
- **直播老师动态来源**：每个直播老师账号自动生成专属动态来源（`live_teacher_${uid}` / `直播（姓名）`），新增直播老师账号后无需手动配置。
- **角色线索权限**：后台按角色配置"线索管理"权限与"来源范围"；支持"全部直播账号来源"虚拟选项（勾选后每个直播老师账号自动只看自己的来源客户）。

### 工作台（首页仪表盘）

- 管理员/运营管理员视角：全部客户、今日新增、今日沟通记录、本月签单、累计签单、有效签单金额；客户质量分析、客户来源效果、咨询师工作情况、客户转化漏斗。
- 直播/投流老师视角：本月新增并分发、本月有进度客户、本月签单客户、今日客户动态、来源效果、团队/咨询师统计。
- 咨询师视角：我的客户、今日分配、待跟进、今日已沟通、已签单、有效签单金额；团队待处理/今日待处理提醒。

### 消息通知

- 站内消息：客户分发、重新分发、转移、跟进反馈等事件推送；顶栏未读角标 1 分钟轮询 + 页面回前台/聚焦时实时刷新。

### 字典与系统管理

- 客户状态管理、线索来源管理（含角色线索权限配置）。
- 继承 `vk-unicloud-admin`：用户管理、角色管理、权限管理、菜单管理、应用管理、素材管理、系统日志、App 升级中心等。

## 二、角色与权限体系

| 角色标识 | 名称 | 定位 |
|---|---|---|
| `admin` / `super_admin` / `administrator` | 超级管理员 | 全部权限，含账号体系管理 |
| `operator` | 运营管理员 | **客户管理体验与超管一致**（全量客户、字典维护、回收站），但不含系统级账号管理（用户/角色/权限/菜单） |
| `consultant` | 咨询师 | 只查看和处理**自己名下**的客户（`consultant_id = uid`） |
| `live_teacher` | 直播老师 | 只看**自己账号动态来源**的客户，数据严格隔离 |
| `traffic_teacher` | 投流老师 | 管理通用来源（视频号/抖音）的客户 |

### 数据隔离机制（服务端强制）

- `applyCustomerAccessWhere`（云端业务校验核心）：
  - 超管/运营管理员：不过滤（全量可见）
  - 直播/投流老师（`isLeadProviderUser`，按**角色/身份关键词**判定）：`source in (该用户可见来源)`
  - 咨询师等其他角色：`consultant_id = uid`（只看自己名下客户）
- 前端只负责展示与交互，**不以隐藏按钮作为唯一权限控制手段**；关键操作（转移、删除、彻底删除、字典维护）均有云端二次校验。
- 角色标识符约定：一律 snake_case 小写英文；**新角色标识符绝不能包含 "admin" 子串**（`App.vue` 与 `getMenu.js` 的 substring 判断会让含 admin 子串的角色自动获得"免登录检查 + 全量菜单"，等于隐形超管）。

## 三、技术栈

- **前端**：uni-app（Vue2）+ Element UI + vk-unicloud-admin（万能表格/万能表单/万能弹窗组件）+ umy-ui
- **云端**：uniCloud 云函数 + 云数据库（`router` 单云函数，vk-unicloud-router 路由模式），适配支付宝云空间
- **身份**：uni-id（账号/角色/权限/token），云函数内 uni-id 3.x
- **部署形态**：H5 PC 管理端（本地 `localhost:8080/admin/` 开发运行）

## 五、快速开始 / 部署

### 环境要求

- HBuilderX（最新版，含 uniCloud 支持）
- uniCloud 服务空间（本项目使用**支付宝云**）

### 部署步骤

1. **关联服务空间**：HBuilderX 中右键 `uniCloud-alipay` 目录 →「关联云服务空间」→ 选择目标空间（前端连接哪个空间由 HBuilderX 关联决定，项目未硬编码 spaceId）。
2. **初始化数据库**：右键 `uniCloud-alipay/database` 目录 →「上传所有 DB Schema 及初始化数据」。会创建全部集合并导入初始数据（菜单、角色、权限、字典、初始管理员）。
   - 注意：支付宝云禁止自定义集合以 `uni-` 开头（官方保留前缀），本项目字典集合已用 `tm-` 前缀（`tm-customer-statuses` / `tm-lead-sources`）。
3. **上传云函数**：右键 `uniCloud-alipay/cloudfunctions/router` →「上传并运行」（需连同 uni_modules 公共模块一起上传）。
4. **运行前端**：HBuilderX「运行到浏览器」，访问 `http://localhost:8080/admin/`。

> 云函数修改后必须手动右键"上传并运行"才会生效；前端 .vue 修改后 HBuilderX 自动重编译，浏览器需 Ctrl+Shift+R 强刷（H5 有缓存）。

### 初始账号

| 账号 | 密码 | 说明 |
|---|---|---|
| `admin` | `123456` | 超级管理员 |

> uni-id 3.x 密码为 HMAC-SHA1（密钥为 `uni-config-center/uni-id/config.json` 的 `passwordSecret`）；如需改密码或重置，可在后台「用户管理」操作。

### 角色初始化

默认角色已固化在 `uni-id-roles.init_data.json`：`admin`（超管）、`operator`（运营管理员）、`consultant`（咨询师）、`live_teacher`（直播老师）、`traffic_teacher`（投流老师）。新环境初始化后，业务用户（咨询师/直播老师等）需在「用户管理」中创建并绑定角色、勾选「允许登录后台」。

## 六、移动端适配

本项目为 H5 PC 管理端，但已针对手机浏览器做了完整适配（功能不缺 + 美观）：

- **全局兜底**（`common/css/app.scss`，≤768px）：弹窗收窄为视口宽度、表单纵向化、表格横向滚动、卡片/工具栏自适应。
- **关键页面 @media**：首页统计卡 2 列、客户列表筛选区可折叠（手机默认收起）、客户详情弹窗网格化、操作按钮 2 列、进度记录时间不竖排等。
- 桌面端（>768px）布局不受影响。

## 七、常见问题

### 1. 登录提示"用户不存在"（数据库中明明有该用户）

多端用户隔离机制导致：在后台「应用管理」配置本项目 appid（见 `manifest.json` 的 `appid`），并在「用户管理」中勾选该用户允许登录的端。

### 2. 上传文件报 CORS 错误（H5 端）

支付宝云对象存储需配置跨域规则：在空间「对象存储 → 跨域设置」添加来源 `http://localhost:8080`（及正式域名），允许 PUT/POST/GET/HEAD 方法。

### 3. 改完云函数不生效 / 报"云函数运行异常"

云函数修改后必须右键「上传并运行」，HBuilderX 不会自动上传云函数。

### 4. 重新初始化数据库报 `E11000 duplicate key`

支付宝云「初始化云数据库」不幂等：集合已有数据时重复导入会冲突。需先在控制台清空/删除集合，再重新上传。

### 5. 新增直播老师账号后，其来源未出现在下拉/角色配置

直播老师动态来源由账号自动生成（识别 `live_teacher` / `zhibo` / 昵称含"直播/主播"等）。确认账号 `status` 非冻结、`allow_login_background` 为 true；角色配置中建议勾选"全部直播账号来源"（虚拟项 `live`），后端会按账号自动展开。
